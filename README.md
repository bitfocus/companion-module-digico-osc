See [HELP.md](./companion/HELP.md) and [LICENSE](./LICENSE)

## Getting started

Set up your DiGiCo console as though companion were an iPad, with send and receive ports as needed.
You can also connect the DiGiCo iPad app to the module, by selecting iPad in the config, then choosing the iPad's IP and ports. The iPad can then send and receive console messages so that both can be used, with feedback.
